# V1 scope and decisions

The roadmap is the source of truth. Items marked **Awaiting confirmation** are proposals until the project owner confirms them.

## In V1.0

- Places and heritage: listings, details, categories, and verified timings and locations
- Food and cafes: listings, details, filters, price range and verified opening hours
- Map of verified places with filters, marker previews and detail links
- Search across places, restaurants, cafes, temples and heritage sites
- News with publication date and source
- Events with date, venue, category and organizer
- Ama Bus route directory, route details and stops
- Railway and airport information, clearly labelled as scheduled information
- Backend, admin publishing, authentication and roles
- Responsive design, SEO basics, testing and rollback

## Excluded from V1.0

| Release | Excluded features                                                                                                           |
| ------- | --------------------------------------------------------------------------------------------------------------------------- |
| V1.1    | Post-launch fixes and feedback improvements                                                                                 |
| V1.2    | Improved search, filters, map experience and nearby results                                                                 |
| V2.0    | AI assistant, trip planner, user accounts, favorites, reviews, business profiles, event submissions and recommendations     |
| V3.0    | Authorized live data, alerts, monetization, business analytics, deals, community content, advanced routing and gamification |

Admin accounts in V1 are for editors only. Public user accounts remain V2.
